# 🌟 AuraTab — Aesthetic Animated Chrome New Tab Extension

An ultra-sleek, interactive, and customizable Chrome New Tab extension featuring dynamic particle physics, real-time clock with Bengali greetings, ambient rain audio, glassmorphism UI, and productivity widgets.

![AuraTab Preview](icon.png)

---

## ✨ Features

- 🌌 **Interactive Particle Canvas:** Real-time physics-based particles that connect and interact dynamically with your mouse.
- ⏰ **Glow Digital Clock & Bengali Greetings:** Displays 12-hour live time and changes warm greetings based on the time of day (শুভ সকাল, শুভ দুপুর, শুভ সন্ধ্যা, etc.).
- 🎨 **4 Neon Aesthetic Themes:**
  - 🔮 **Cyberpunk** (Neon Pink & Cyan)
  - 🌌 **Deep Space** (Cosmic Indigo & Sky Blue)
  - 🌅 **Lo-fi Sunset** (Peach Orange & Twilight Purple)
  - ⚡ **Matrix** (Neon Emerald Green)
- 🌧️ **Ambient Rain Audio (Synthesized):** Built-in rain sound generator using Web Audio API for calm study and coding sessions (no external audio files needed).
- 🚀 **Glassmorphism Search & Quick Launch:** Google search bar and sleek glowing shortcut cards for YouTube, GitHub, ChatGPT, Facebook, Reddit, and Gmail.
- 🎯 **Daily Focus & To-Do Drawer:** Quickly jot down tasks and track completed goals with persistent local storage.
- 💡 **Inspirational Daily Quotes:** Bengali motivational quotes to keep you energized.

---

## 🛠️ How to Install in Google Chrome

1. Open Google Chrome and navigate to:
   ```text
   chrome://extensions
   ```
2. Enable **Developer mode** toggle in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select this directory:
   ```text
   aesthetic-newtab-extension
   ```
5. Open a new tab (`Ctrl + T`) and enjoy your new aesthetic dashboard!
